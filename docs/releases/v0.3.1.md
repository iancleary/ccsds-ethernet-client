# v0.3.1

This patch adds benchmark examples, validation, and documentation. The Rust
library API and Python API are unchanged.

- Add configurable workloads and a synthetic peer with root-free simulation
  and an isolated Linux namespace/veth backend that uses the packet transport.
- Support rate sweeps, bursts, payload sizes, queue capacities, independent
  telemetry, peer delays, and deterministic acknowledgement loss.
- Report versioned JSON Lines with latency, telemetry age, loss, pacing,
  queue counters, process CPU, allocation counts, and local reopen timing.
- Add benchmark contract tests to local checks, CI, and release verification.

The synthetic peer uses a benchmark-only protocol, not a CCSDS application
protocol. The harness does not target physical interfaces. Physical-peer
validation requires an explicit consumer-owned adapter and remains future work.

Sampled rates are not qualified throughput limits. CPU and allocation counts
include the generator, peer, transport, and measurement overhead. Reopen timing
does not measure remote reboot recovery. See `docs/benchmark.md` for the full
measurement contract and limitations.
